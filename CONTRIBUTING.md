# Contributing

## about the widget

Documenting this for myself mostly:
- There is a bundling step involved because we're importing a local Javascript
file in `widget.js`. 
    - There's more information about it in the [anywidget
    docs](https://anywidget.dev/en/bundling/), but naturally I skipped over it
    until I actually encountered this need in a project.
- The Javascript file that contains the widget frontend
(`src/scattered/widget.js`) is generated by esbuild (from `lib/widget.js`), and
it is .gitignored. It should be generated by running `pnpm widget-dev` or `pnpm
widget-build`.

## automated releases

We're using [Release Please](https://github.com/googleapis/release-please) to
manage releases. Versions of the two packages (JS library and Python widget)
are kept in sync (via the `x-release-please-version` marker in
`pyproject.toml`). 

Version bumps are determined based on the [conventional commit
messages](https://www.conventionalcommits.org/en/v1.0.0/). Roughly:
- `fix` = patch bump
- `feat` = minor bump
- `feat!` or `fix!` = major bump

The changes are accumulate in a release PR. When merged, both the JS and Python
packages are published on NPM and PyPI, respectively.
